# DevTrack

Plataforma de gestão de estudos para desenvolvedores.

## Estrutura do Projeto
- `devtrack-backend` - Backend Spring Boot
- `devtrack-frontend` - Frontend React + Vite

## Tecnologias
- Java 21, Spring Boot, PostgreSQL
- React, Vite, TypeScript
- Autenticação JWT

## Rodando o Projeto
1. Clone o repositório
2. Configure o banco de dados e variáveis de ambiente
3. Rode o backend (`cd devtrack-backend && ./mvnw spring-boot:run`)
4. Rode o frontend (`cd devtrack-frontend && npm install && npm run dev`)

Para detalhes específicos do backend e frontend, veja:
- [Backend README](devtrack-backend/README.md)
- [Frontend README](devtrack-frontend/README.md)
